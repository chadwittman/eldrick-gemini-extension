# ELDRICK for Gemini CLI

Golf club fitting in Gemini CLI. ELDRICK fits drivers, fairway woods, hybrids, irons and wedges, and matches the specs to real heads, shafts and grips. Built on 100,000+ fittings: trained on 80,000, plus 25,000+ ELDRICK has done itself.

## Install

```sh
gemini extensions install https://github.com/chadwittman/eldrick-gemini-extension
```

Then start `gemini` and run `/mcp auth eldrick` to sign in with your ELDRICK account. A new email gets an account with a 6-digit code.

## What you can ask

- "Fit me for a driver. I swing 98 mph and fade it."
- "Compare the Ping G440 Max and the Qi4D Max."
- "Which irons suit an 82 mph 7-iron?"

Searching, comparing and scoring clubs are free. Each fitting uses one of your account's included fittings.
